# M12 机会补牢 — 第一性原理

> **模块**: M12 Opportunity Catcher（机会补牢）
> **创建**: 2026-04-28
> **一句话定位**: 价格是最终验证 — 当市场已用真金白银投票时，反向溯源找原因，判断趋势能否延续。

---

## 存在意义

现有管线是**正向推理**：新闻事件 → 信号 → 判断 → 行动。这是预测型操作。

但市场中有大量机会，我们**没有预测到**，而市场**已经用价格验证了**：

- 央行降准前一天，市场已经有人知道了
- 产业政策出台前，板块已经异动
- 业绩超预期前，股价已经提前反应

M12的存在意义是：**不放过后验验证的机会**。价格异动本身就是最高质量的信号 — 因为有人已经用真金白银投了票。

M12不是追高。追高是无脑入场。M12是**反向溯源 + 趋势阶段判断**，回答三个问题：

1. **为什么涨？** — 反向溯源找原因
2. **还能涨吗？** — 判断趋势阶段（early/middle/late）
3. **还安全吗？** — 更紧的止损保护入场偏晚的代价

---

## 核心约束（永远不能违反）

1. **价格是最终验证** — 异动股票不是猜测，是已验证的事实。但验证的是"有事情发生了"，不是"还会继续涨"。

2. **溯因必须有证据** — 每次补牢必须连到明确原因（新闻/政策/财报/事件）。找不到原因的异动 = 放弃。无因追高 = 赌博。

3. **止损比入场更重要** — 补牢入场比正向信号入场偏晚，止损必须更紧。M12推荐止损候选，M4最终决策。

4. **趋势阶段是核心判断** — early可补，middle谨慎，late放弃。不是所有异动都值得入场。

5. **市场规则不可违反** — T+1/涨跌停/最小手数由 core/market_rules 管理，M12不分设规则。

6. **不是追高** — 异动已消耗大部分空间时，选择不入场。空列表 `[]` 是合法输出。

7. **多策略平行验证** — 推荐多个止损策略候选，M9模拟对比，M4最终选择。M12不替M4做决策。

8. **信号溯源** — 每笔补牢持仓必须标注 `origin="opportunity_catcher"`，供M6复盘统计。

9. **与M3协作不替代** — 趋势持续性判断复用M3的 judge()，不自建判断逻辑。

10. **埋点标签供复盘** — anomaly_type/market/trend_stage/causation_type 等标签供M6交叉统计，数据驱动迭代。

## 模块边界

### M12 做什么

| 职责 | 说明 |
|------|------|
| 异动检测 | 扫描全市场价格，识别统计显著异动（ATR+σ+量比） |
| 反向溯源 | 对异动股票定向采集新闻，复用M1解码，找异动原因 |
| 趋势阶段判断 | 判断异动处于 early/middle/late 阶段 |
| 推荐止损候选 | 基于趋势阶段和市场规则，给出止损策略候选列表 |
| 市场差异化 | A股/港股/美股不同的扫描频率、数据源、止损策略 |

### M12 不做什么

| 职责 | 归属模块 | 原因 |
|------|---------|------|
| 止损策略最终决策 | M4 | M4根据风险预算+整体持仓做最终决策 |
| 交易执行规则 | core/market_rules | 已有统一市场规则 |
| 复盘归因 | M6 | M6按origin字段统计补牢胜率 |
| 策略参数回测 | M7 | M7验证历史异动收益 |
| 实际开仓 | M9 | M9执行模拟/实盘交易 |

## 数据流

```
输入：
  价格数据 (Baostock/YFinance)
  ↓
M12 异动检测 → PriceAnomaly[]
  ↓
M12 反向溯源 → CausationResult[]
  ↓                 (复用M0定向采集 + M1解码 + M10情绪)
M12 趋势判断 → TrendAssessment[]
  ↓                 (复用M3 judge)
M12 输出 → RetroOpportunity[]
  ↓                (包含 OpportunityObject + 止损候选)
M4 行动设计 → 选择止损策略 + 确定仓位
  ↓
M9 模拟交易 → 多策略平行模拟
  ↓
M6 复盘归因 → 按标签交叉统计胜率
```

## 市场差异化

### A股（T+1）

- 盘中快速扫描（30分钟间隔） + 盘后全量扫描
- 涨停股不入场，标记观察池
- 入场时机：次日开盘
- 止损候选：5% / ATR×2 / 次日低开3%
- 最短持有：1天

### 港股（T+0）

- 盘中扫描（30分钟间隔）
- 入场时机：异动确认后立即
- 止损候选：3% / ATR×1.5 / 分时破位
- 最短持有：15分钟

### 美股（T+0）

- 盘中扫描（北京时间夜间，30分钟间隔）
- 入场时机：异动确认后立即
- 止损候选：2% / ATR×1 / VWAP破位
- 最短持有：5分钟

## 关键词

- **异动 (Anomaly)**: 统计显著的价格+成交量变化
- **反向溯源 (Backward Causation)**: 从结果找原因
- **趋势阶段 (Trend Stage)**: early/middle/late 判断
- **补牢 (Catching)**: 后验入场，不是追高
- **观察池 (Watch Pool)**: 涨停等无法入场的异动，标记观察
