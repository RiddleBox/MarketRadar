## 🎯 核心问题诊断

### 1. 新闻信号完全缺失 ⚠️ **CRITICAL**

**现象**:
- 信号数据库中 264 条信号全部为"市场情绪快照"类型
- 最近 7 天 128 条信号，无一条来自新闻推理
- 新闻采集任务显示"成功"，但实际一直失败

**根因**:
1. **导入路径错误** (已修复 ✅)
   - 调度器中: `akshare_provider.AKShareNewsProvider`
   - 实际应为: `akshare_news.AkshareNewsProvider`
   - 位置: `m7_scheduler/scheduler.py:668`

2. **AKShare 库正则表达式错误** (待修复 🔧)
   - 错误: `Invalid regular expression: invalid escape sequence: \u`
   - 来源: `akshare.stock_news_em()` 内部实现
   - 可能原因: AKShare 版本兼容性问题

3. **错误处理机制缺陷**
   - 异常被 try-except 吞掉，未记录到日志
   - 调度器显示任务"成功"，实际返回空列表
   - 建议: 增强错误日志和监控

**影响范围**:
- M0 新闻采集 → 完全失效
- M1 新闻解码 → 无输入数据
- M3 新闻信号生成 → 无法工作
- M12 机会判断 → 缺少关键信号源

**修复状态**:
- ✅ 导入路径已修复 (commit 801d5399)
- 🔧 AKShare 正则表达式问题待解决
- ⏳ 需要验证修复后的完整流程

---

### 2. 机会判断未产生结果 ⚠️ **HIGH**

**现象**:
- 三个市场（A股/港股/美股）均未发现机会
- 无法判断是真的没有机会，还是判断逻辑有问题

**可能原因**:
1. **信号源缺失**: 新闻信号完全缺失（见问题1）
2. **阈值过高**: M3 判断引擎的机会阈值可能过于严格
3. **逻辑问题**: M12 机会判断逻辑可能存在 bug

**诊断工具**:
- 已创建 `test_signal_judgment.py` 用于测试 M3 判断引擎
- 可以分析信号评分分布，测试机会生成逻辑

**下一步**:
1. 先修复新闻采集问题（问题1）
2. 运行 `test_signal_judgment.py` 诊断 M3 引擎
3. 检查 M12 机会判断的阈值和逻辑
