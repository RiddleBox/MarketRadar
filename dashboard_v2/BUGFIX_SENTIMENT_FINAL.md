## 问题1：采集超时

### 原因
- 原超时设置：60秒
- 实际采集耗时：约74秒（1分14秒）
- 采集包含11个步骤，需要从多个数据源获取数据

### 修复方案
将超时时间从 60秒 增加到 **180秒（3分钟）**

```python
result = subprocess.run(
    [sys.executable, "-m", "m7_scheduler.cli", "run", "sentiment_collect"],
    timeout=180,  # 从60秒增加到180秒
)
```

### 采集步骤分析
情绪采集包含以下数据源（通过 AKShare）：
1. 股票综合评分（东方财富）
2. 百度热搜
3. 北向资金流向
4. 微博情绪
5. 东财热股统计
6. 涨跌家数统计
7. 个股评分分布
8. 市场宽度指标
9. 社交热度分析
10. 数据合成与计算
11. 数据库保存

**实测耗时**: 74.5秒

## 问题2：市场划分不清晰

### 当前情况
情绪采集**专门针对A股市场**，原因：

1. **北向资金** - 外资通过沪深港通买入A股的资金流向
2. **东方财富评分** - 仅覆盖A股市场
3. **百度热搜** - 主要关注A股标的
4. **微博情绪** - 主要讨论A股
5. **涨跌家数** - 基于A股市场统计

### 为什么不支持港股/美股？

**数据源限制**:
- 北向资金是A股特有的概念（外资通过港股通买入A股）
- 东方财富、百度、微博等数据源主要覆盖A股
- 港股和美股需要不同的情绪指标和数据源

### 修复方案
在页面添加明确说明：

```python
st.title("🧠 市场情绪分析")
st.caption("📊 当前仅支持 A 股市场情绪分析（基于北向资金、东财评分、百度热搜、微博情绪）")
```

## 使用说明

### 手动采集情绪数据
1. 访问 Dashboard 情绪面页面
2. 点击"🔄 立即采集"按钮
3. 等待约1-2分钟（显示"正在采集市场情绪..."）
4. 采集完成后页面自动刷新
5. 查看恐贪指数、市场情绪、方向、强度等指标

### 自动采集
调度器会在 09:00-22:00 期间每30分钟自动采集一次情绪数据。

### 数据说明
- **恐贪指数**: 0-100，综合市场情绪指标
  - 0-20: 极度恐惧
  - 20-45: 恐惧
  - 45-55: 中性
  - 55-75: 贪婪
  - 75-100: 极度贪婪
- **方向**: BULLISH（看多）/ BEARISH（看空）/ NEUTRAL（中性）
- **强度**: 1-10，情绪强度评分
- **北向资金**: 外资净流入金额（亿元）
